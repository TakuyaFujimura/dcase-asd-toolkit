# ASDKit v1.0.0 Release Notes

Changes in v1.0.0 are summarized below.
To use models trained with v0.0.0, see the [legacy migration guide](../asdkit/legacy/v0_to_v1/README.md).


## User Interface

- **Installation:** Added `pyproject.toml`, uv-based setup, and environment activation via `jobs/activate.sh`. See [Easy Start](../README.md#-easy-start) in the README.

- **Recipes:** Moved run scripts from `jobs/asd/call/` to `jobs/asd/run/` and renamed `ae.sh` to `dcase_ae.sh`. Other script names are unchanged. See Supported Methods in the README.

## Processing Changes

- **Extraction:** Replaced `<split>_extract.npz` with a `<split>_extract/` directory containing one `.npy` file per item, plus `<split>_extract.metadata.json`. Memory-mapped loading can reduce memory usage.

- **Scoring:** kNN-based backends now exclude self matches when computing anomaly scores for fitted training samples.

- **Classification losses:** Improved numerical stability in SubClusterAdaCos and AdaProj by avoiding `log(softmax(...))`.

## New Methods

- **Backends:** [Relative Deviation Pooling (RDP)](https://arxiv.org/abs/2603.04605), [BEAM, AdaBEAM](https://arxiv.org/abs/2603.13749), and [variance-minimization-based rescaling](https://dcase.community/documents/workshop2025/proceedings/DCASE2025Workshop_Matsumoto_12.pdf)
- **SSL Models:**
    - [Dasheng](https://arxiv.org/abs/2406.06992)
    - [EAT](https://huggingface.co/worstchan/EAT-base_epoch30_pretrain) without fairseq
    - See [Optional dependencies and pre-trained model usage](../README.md#optional-dependencies-and-pre-trained-model-usage) for setup instructions.
